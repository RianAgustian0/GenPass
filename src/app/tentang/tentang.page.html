Password Generator

Tentang

Aplikasi untuk membuat kata sandi dengan berbagai opsi kustomisasi.

Fitur

  • Generate password acak
  • Atur panjang password
  • Huruf, angka, simbol
  • Simpan & lihat riwayat password

Cara Pakai

1. Atur panjang dan karakter
2. Klik “Hasilkan Baru”
3. Salin atau simpan password

Developer

Informasi Data

Semua data disimpan secara lokal menggunakan Ionic Storage dan tidak dikirim ke server.
